# План этапа III — не реализован


Использовать одни и те же записи после отдельно проверенного ресемплинга. Контрольные варианты:

| Метод | Определение | Что заведомо меняется |
|---|---|---|
| Нет нормировки | y=x | Сохраняются исходные шкалы, включая несопоставимость единиц |
| Индивидуальная z | y=(x−μx)/σx, σ с делением на N | Среднее 0, СКО 1; межзаписной уровень стирается |
| Индивидуальный максимум | y=x/max\|x\| | Максимум модуля 1; чувствительность к выбросу |
| Индивидуальный RMS | y=x/sqrt(mean(x²)) | RMS 1; различия абсолютного RMS стираются |
| Общая z внутри набора | y=(x−μd,train)/σd,train | Один аффинный масштаб для всех классов набора |
| Общий эталон внутри набора | y=x/sd,train | Общий положительный масштаб; центрирование не подразумевается |

Эталонный масштаб предложено начать с медианы RMS обучающих записей без использования класса. Вариант по исправным обучающим образцам можно рассматривать отдельно: он требует H в обучении и явного протокола. Сейчас HUSTbearing такого локального H не имеет. Равный вес записям или вес по числу отсчётов для общих параметров нужно выбрать заранее; иначе длинные файлы изменят итоговый масштаб. При равном весе записям общая дисперсия учитывает и внутрезаписной разброс, и различие средних, а не только среднее частных дисперсий.

Разделение выполнять по независимому подшипнику/опыту до оценки любых общих параметров. Если таких ID нет, независимость не объявлять доказанной и не выдавать различия 14 фрагментов за популяционные результаты. Оценка общего масштаба на всём наборе вместе с проверочными файлами — утечка. Нормировка тестовой записи по её истинному классу недопустима: класс неизвестен при применении. Слова преподавателя «внутри классов» в разговоре неоднозначны; классовую нормировку нельзя молча вводить как утверждённый алгоритм.

Индивидуальная z/max/RMS использует только наблюдаемую запись и сама по себе не требует истинной метки, но удаляет часть амплитудной информации. Длина записи для такого расчёта должна соответствовать будущему сценарию применения; глобальные/эталонные параметры всегда fit только на обучающей части.

Сравнить заранее заданные отношения амплитуд H/OR/IR в сопоставимых условиях, среднее/RMS/СКО, устойчивость к выбросам, форму амплитудных распределений и спектров. Для преобразования x→ax+b центрированный амплитудный спектр масштабируется на |a|; одна нормировка не сближает произвольные формы спектров. Классовые различия анализировать описательно без обучения на этом этапе. Лучший метод заранее не назначать; цель может потребовать сохранять исходный масштаб как отдельный признак, но это отдельное будущее решение.

Важное уточнение определений: в U4, PDF-страница 6 / печатная 5, RMS обозначает sqrt(mean((x−μ)²)), то есть СКЗ переменной составляющей. В этом плане `RMS_raw=sqrt(mean(x²))` и `std_centered=sqrt(mean((x−μ)²))` различаются: RMS_raw²=std_centered²+μ². Перед экспериментом это соглашение нужно сохранить в названиях полей. Пик-фактор пособия CF_centered=max|x−μ|/std_centered и центральный эксцесс инвариантны к каждому невырожденному аффинному преобразованию. Поэтому для шести указанных способов они не могут сами по себе определить «лучшую нормировку»; нужны показатели абсолютного уровня и межзаписных отношений. Вариант CF_raw=max|x|/RMS_raw — другой показатель и должен быть подписан отдельно. Это математические свойства, а не уже полученные результаты нормировочного эксперимента.


Нужны H/IR/OR HUSTbearing, IR Paderborn, согласованные режимы MFPT, повторные независимые экземпляры и паспорта единиц. Сначала определить идентификаторы опытов и протокол разделения. По 14 фрагментам нельзя выбрать универсально лучший метод.
